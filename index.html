WAVEDECK — 시작하기 전에

◔
어떤 데이터를 보나요

Open-Meteo 전지구 파랑모델에서 파고·주기·스웰·바람·수온·물때를 가져옵니다. 실시간 관측이 아니라 예측치이고, 정확한 물때·실측은 국립해양조사원·기상청에서 확인하세요.

◑
점수는 무엇을 뜻하나요

파고·주기·바람·스웰 방향·정돈도 다섯 가지를 0~10으로 합칩니다. 점수 옆 막대가 항목별 기여도예요. 해변의 지형 조건을 직접 입력하면 그때부터 점수에 반영됩니다.

◕
믿으면 안 되는 것

모델 격자가 수십 km라 이웃한 해변은 값이 거의 같습니다. 만 안쪽·방파제 같은 국지 지형은 직접 입력해야 반영되고, 물때는 근사값입니다. 입수 전 현장 상황과 기상청 특보를 꼭 확인하세요.

◉
실시간 체크인

모델이 못 잡는 이웃 해변의 차이는 현장 사람들의 체크인으로 메웁니다. 지금 어디에 몇 명이, 탈 만한지·붐비는지 투표가 쌓이고 2시간만 유효합니다. 해변 반경 안이면 '현장 인증'으로 올라가 더 믿을 만한 신호가 됩니다. 지역 화면에서 해변끼리 비교해 좋은 쪽으로 옮겨 타세요.
